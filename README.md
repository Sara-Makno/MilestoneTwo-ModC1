MilestoneTwoModC1

This repository contains my weekly Jupyter Notebook work for Module C: Data Science Capstone – Milestone Two.

Project Topic

This project focuses on using machine learning to support breast cancer classification. The analysis compares two breast cancer datasets:

Breast Cancer Wisconsin Diagnostic DatasetContains tumor morphology measurements such as radius, texture, perimeter, area, smoothness, compactness, concavity, and diagnosis.

Breast Cancer Coimbra DatasetContains patient-level clinical and blood-based biomarkers such as age, BMI, glucose, insulin, HOMA, leptin, adiponectin, resistin, and MCP-1.

The goal is to evaluate how well supervised and unsupervised machine learning techniques can identify meaningful patterns and distinguish between benign and malignant or cancer-positive cases.

Notebooks Included

This repository includes notebooks for Weeks 8–11:

Week 8: K-Nearest Neighbors with multiple distance metrics

Week 9: Gradient Boosting and hyperparameter tuning

Week 10: K-Means Clustering and Silhouette Score

Week 11: DBSCAN, Hierarchical Agglomerative Clustering, Linkage Methods, and Dendrograms

Combined Notebook: Weeks 8–11 summary notebook

Analytical Focus

The notebooks examine:

Classification performance across both datasets

Model evaluation using accuracy, precision, recall, F1-score, and ROC-AUC

Hyperparameter tuning and strategies used to reduce overfitting

Cluster quality using silhouette scores and visual analysis

Differences between direct tumor morphology features and indirect clinical biomarkers

The usefulness of exploratory data analysis in guiding model selection and interpretation

Purpose

This repository supports my Milestone Two submission for Module C by documenting the code, model outputs, figures, metrics, clustering results, and conclusions completed across Weeks 8–11.

The notebooks provide the technical evidence used in the written Milestone Two paper and demonstrate the progression from supervised classification methods to unsupervised clustering techniques.
